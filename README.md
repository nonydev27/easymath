# Welcome to MathKids 👋

This is the official repository for **MathKids**, a mobile application built with [Expo](https://expo.dev) designed to help children aged **4 – 10** master mathematical concepts through interactive play.

## About the Project

**MathKids** is dedicated to making numbers click. By leveraging engaging visuals and intuitive file-based routing, we provide a seamless learning experience that helps young learners grasp everything from basic counting to foundational arithmetic.
